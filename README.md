Preview CSV files with intelligent auto-delimiter detection. Convert to JSON, sort columns, filter data, and export to multiple formats.

## Features

- Auto-detects delimiter (comma, tab, semicolon, pipe)
- Table view with sortable columns and basic filtering
- Convert CSV to JSON (array of objects or raw arrays)
- Export to CSV, JSON, or TXT
- Paste or paste from clipboard; no server upload

## Why use this tool

Inspect CSV exports, convert spreadsheets to JSON for APIs or scripts, or quickly check delimiter and encoding before importing elsewhere.
